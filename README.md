# Banking System – C++ OOP Project

A console-based banking system implemented in **C++** using **Object-Oriented Programming (OOP)** principles.  
The system simulates basic banking operations such as account creation, deposits, withdrawals, transfers, and interest calculation, with transaction logging to a file.

---

## 📌 Features

- Create Savings and Checking accounts
- Deposit money into accounts
- Withdraw money with validation
- Transfer money between accounts
- Interest calculation for savings accounts
- Transaction logging to a text file
- Admin view for all accounts
- Track number of active accounts using static members

---

## 🧠 OOP Concepts Used

- Inheritance
- Polymorphism
- Virtual functions and destructors
- Encapsulation
- Static members
- Abstract base classes

---

## 🛠 Technologies Used

- C++
- STL (`unordered_map`)
- File handling
- Exception handling
